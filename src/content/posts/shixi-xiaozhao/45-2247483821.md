概念

滑动窗口是**线性时间复杂度**的双指针优化算法，核心是在数组、字符串等线性结构中，通过维护一个**连续的动态区间（窗口）**，用两个指针界定窗口边界并单向移动调整，在一次遍历中完成目标求解，以此替代暴力枚举所有子区间的低效做法，将原本 O (n²) 的时间复杂度优化为 O (n)。

简单来说就是用一个窗口去框所有符合条件的内容，而这个窗口由左边界left，右边界right来建立，并通过这个动态窗口来遍历所有目标。

简单例题

  给你一个由 n 个字符组成的字符串s。请你找出无重复字符的最长连续子字符串，并输出其长度。

  解：(解题时需注意：边界位置的处理，字串包含字符及字符位置的记录)

先假设字符串s为：abckbcb

最初左边界left与右边界right均为0，也就是都指向a，随着右边界right的移动，子字符串逐渐+1，且每移动一次，均需校验right指向字母是否被子字符串包含，若被包含则left位置更新。

实现：

```python
def longestSubstring(s: str) -> int:
   last_occur = {}    #记录子串包含字符及其最新位置
   left = 0  # 滑动窗口左边界
   max_len = 0  # 最长无重复子串长度
   str_len = len(s)  # 字符串长度

      for right in range(str_len):
      curr_char = s[right]
      # 若当前字符已出现且在窗口内（最后出现位置>=左边界），调整左边界
      if last_occur.get(curr_char, -1) >= left:
         left = last_occur[curr_char] + 1

      # 更新当前字符的最后出现位置
      last_occur[curr_char] = right

      # 计算当前窗口长度并更新最大值
      curr_len = right - left + 1
      if curr_len > max_len:
         max_len = curr_len
return max_len
```

以上思路也可考察于：连续n个数字的最大和，连续n个数字的最大平均值等等。
